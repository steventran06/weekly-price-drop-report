# Wednesday Price-Drop Google Business Profile Post Patch

This patch adds a ready-to-copy Google Business Profile post to the existing Wednesday `npm run weekly` workflow.

## What it does

- Uses the existing OpenAI content-generation call. It does **not** add another API request.
- Generates one standalone Google Business Profile post summarizing the selected 4-5 price-drop homes.
- Aims for roughly 1,050-1,350 characters.
- Hard-caps the final post at 1,500 characters including spaces.
- Does not include street addresses, MLS numbers, hashtags, or Markdown.
- Ends with:

  `Want details on any of these homes? Visit PortlandHomeGuide.com.`

- Adds the post to both the plain-text and HTML Wednesday report email.
- Shows the exact character count in the email.
- Saves a copy locally to:

  `output/google-business-post.txt`

- Also includes the post in `output/weekly-analysis.json` and `output/weekly-report.md`.

## Install

From the root of `weekly-price-drop-report`:

```bash
unzip -o ~/Downloads/price-drop-google-business-post-patch.zip -d .
```

## Test

First type-check:

```bash
NODE_OPTIONS=--max-old-space-size=2048 npm run build
```

Then run the Wednesday workflow manually:

```bash
npm run weekly
```

After it completes, verify:

```bash
cat output/google-business-post.txt
```

The Wednesday email should now contain a section titled `Google Business Profile Post` with a `X/1500 characters` counter and copy/paste-ready text.

## Update: direct weekly blog link

The Google Business Profile post now ends with the exact dated weekly article URL:

`https://blog.steventranrealestate.com/posts/portland-metro-price-drops-<date>/`

The URL is generated by the application using the same `createPriceDropBlogUrl()` helper already used by the YouTube description, so the model does not invent or guess the link.

Street addresses and MLS numbers remain out of the Google Business copy to preserve the 1,500-character budget; the linked article contains the full property details.
